*Activate key command*

Marks a key as active\.

Use this when a key should be available for normal tracking and use again\.

*Usage*

`/activatekey key_id`

Required input:
\- `key_id`: the number of the key\.

*Example*

`/activatekey 2`

Activates key 2\.

>Important:
>\- `key_id` must be a positive number\.
>\- The key must exist\.
>\- This changes the active status only; it does not change the current holder or history\.
